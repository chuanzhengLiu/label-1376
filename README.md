# 霓虹贪吃蛇 (Neon Snake) 🐍

一款使用 HTML5, CSS3, 和 JavaScript 构建的现代霓虹风格贪吃蛇游戏。具有深色主题、发光视觉效果和响应式设计。

## 功能特点

- **视觉效果**: 深色背景 (#0a0a12) 搭配霓虹绿和粉色点缀。
- **图形**: 使用 CSS 阴影和 Canvas 2d 绘图实现的动态发光效果。
- **控制**: 使用方向键移动，空格键暂停/继续。
- **响应式**: Flexbox 布局，适配移动设备（在小屏幕上垂直堆叠）。
- **游戏状态**: 本地存储最高分，多种速度等级，以及游戏结束覆盖层。

## 项目结构

- `index.html`: 游戏主结构和布局。
- `style.css`: 所有视觉样式、动画和响应式规则。
- `script.js`: 游戏逻辑、渲染循环和事件监听。

## 如何开始

1. 在任何现代浏览器中打开 `index.html`。
2. 点击 **开始** 按钮或按 **空格键** 开始游戏。
3. 使用 **方向键** 控制蛇的移动。
4. 吃掉粉色发光的食物来变长并得分。
5. 避免撞墙或撞到自己的尾巴！

## 自定义

你可以在 `script.js` 中调整游戏常量：
- `SPEED_LEVELS`: 调整 3 个预设速度等级。
- `GRID_SIZE`: 更改网格单元的大小。
